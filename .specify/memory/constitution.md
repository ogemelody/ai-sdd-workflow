# Engineering Constitution

## Principles
1. Correctness before speed.
2. Security and privacy by design.
3. Testable, maintainable implementations.
4. Small, reviewable changes.
5. Human accountability for consequential decisions.

## Governance
- Specifications define intended behavior.
- Plans document architecture and trade-offs.
- Tests provide independent evidence of correctness.
- CI checks and repository permissions enforce quality gates.
- Exceptions require documented justification and approval.
