
# Testing Checklist

## Before Implementation
- [ ] Acceptance criteria are testable.
- [ ] Relevant test levels are identified.
- [ ] Failure and boundary cases are considered.

## During Implementation
- [ ] Tests are added or updated.
- [ ] Tests are deterministic.
- [ ] External dependencies are isolated appropriately.
- [ ] Security-sensitive paths are tested.

## Before Pull Request
- [ ] Relevant tests pass locally.
- [ ] Lint and formatting checks pass.
- [ ] Type checks pass where applicable.
- [ ] No secrets or sensitive test data are committed.
- [ ] Test evidence is included in the PR.
- [ ] Known limitations are documented.
